# Contributing

Thanks for your interest in contributing!

## Development

1. Fork the repository.
2. Create a feature branch.
3. Install the project with `pip install -e .`.
4. Install test dependencies with `pip install pytest`.
5. Make your changes and add tests where appropriate.
6. Run `pytest`.
7. Open a pull request with a clear description of the change.

Please keep changes focused and avoid committing generated files or virtual environments.
